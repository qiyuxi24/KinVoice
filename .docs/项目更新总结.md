## 后端 (backend/app/)

### 路由层 (api/) — 9 大模块

| 路由 | 端点 | 功能 | 来源 |
|------|------|------|------|
| `chat` | `POST /chat` | AI 陪伴对话（Cloudie + NVC） | si |
| `memory` | `GET/POST/DELETE /cards` | 经验卡片 CRUD + 收藏 | si |
| `summarize` | `POST /summarize` | 对话总结 | si |
| `chatroom` | `GET/POST /chatroom/*` | 家庭组成员互聊（私聊/群聊） | 新增 |
| `profile` | `CRUD /profiles` | 家庭成员档案 | si |
| `profile_ai` | `POST/GET /profile/ai/*` | AI 自动编写/读取档案 | 新增 |
| `family` | `POST/GET /family/*` | 家庭组创建/加入/退出 | 新增 |
| `tts` | `POST /tts` | 文本转语音 (vivo TTS) | xia |
| `replica` | `POST /replica` | 音色克隆 | xia |

| 服务 | 功能 |
|------|------|
| `llm_service.py` | 大模型统一调用（兼容 xia `call_llm/chat` + si `chat_completion/chat_with_system`），Mock 降级，超时 3600s |
| `cloudie_prompt.py` | Cloudie 陪伴对话 system prompt（温柔、共情、不评判） |
| `card_summarizer.py` | 对话内容 → 经验卡片自动提取 |
| `family_service.py` | 家庭组业务逻辑 |
| `profile_writer.py` | AI 档案编写 |
| `replica_service.py` | 音色克隆 |
| `tts_service.py` | TTS 文本转语音 |

### 数据模型 (models/)

| 模型 | 表 | 核心字段 |
|------|-----|----------|
| `Card` | `cards` | 统一了 NVC 四要素 + 对话收藏（type: nvc/chat_message/chat_conversation） |
| `Conversation` | `conversations` | 对话会话（type: ai/private/group） |
| `ChatMessage` | `chat_messages` | 聊天消息 |
| `FamilyMember` | `family_members` | 家庭成员档案（name, relation, birth_date, content_md） |
| `User` | `users` | 设备用户（UUID） |
| `FamilyGroup` | `family_groups` | 家庭组（8位ID + 6位密码） |
| `FamilyMembership` | `family_memberships` | 用户 ↔ 家庭组关系 |

### 中间件 / 工具

- `middleware/user_identity.py` — 用户身份中间件
- `extractors/base.py` — 对话内容提取器基类
- `extractors/database.py` — 数据库提取器
- `utils/logger.py` — 日志（标准 logging）
- `tests/test_llm_service.py` — LLM 服务测试

### 通信层 (helper/)

#### ajax.js — 完全重写

- 集成错误码体系，`import { getErrorInfo, mapDetailToCode, httpStatusToCode, fetchErrorToCode } from './errorCodes'`
- 统一错误对象格式：`{ code, message, detail, level, raw, isError }`
- QuickApp Studio 代理包装解包（检测 `{ code, headers, data: "JSON字符串" }` 结构并自动解包）
- `Content-Type: application/json` 仅对字符串 body 显式设置（解决快应用 fetch 行为不一致导致的 422）
- 超时定时器清理（`clearTimeout` 防止定时器池耗尽/假死）
- 全局异常处理（`try/catch` 包裹 `requestHandle`）

### 关键架构变化

1. **手动 import 替代 require.context**：快应用不支持 `require.context`，`index.js` 改为手动 import 各模块
2. **用户身份系统**：`userIdentity.js` 用 localStorage UUID 标识设备，`family.js` 和 `chatroom.js` 通过请求体传递 `user_id`
3. **错误码集成**：`ajax.js` 直接 import `errorCodes`，统一错误格式
4. **定时器清理**：`requestHandle` 的 `Promise.race` 增加 `finally` 清理超时定时器，解决快应用假死问题
5. **包名变更**：`cn.nekohackers.kinvoice` → `com.kinvoice.app`
