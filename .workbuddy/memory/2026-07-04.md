# 2026-07-04 工作日志

## 修复快应用前端「使用一段时间后点击无反应」Bug

### 问题根因（按严重程度排列）

| 排名 | 文件 | 问题 | 影响 |
|------|------|------|------|
| 1 | `src/helper/ajax.js` | `Promise.race` 中 20s 超时 setTimeout 从不清理 | 每次 HTTP 请求泄漏一个定时器，累积耗尽定时器池 |
| 2 | `src/pages/Companion/index.ux` | chatHistory 无限增长 + JSON.stringify 阻塞 UI 线程 | 对话越多保存越慢，最终卡死 |
| 3 | `src/helper/navigate.js` | 路由锁 unlocked setTimeout 累积 + 无安全兜底 | 快速切换页面时锁可能意外卡死 |
| 4 | `src/pages/Memory/index.ux` | onShow 无防抖导致 loadFromLocal 并发 | 快速切页产生重复 storage 操作 |
| 5 | `src/pages/ProfileDetail/index.ux` | onShow 每次触发 loadProfiles 无防抖 | 快速切页产生重复 HTTP 请求 |

### 修复内容

1. **`src/helper/ajax.js`**: `requestHandle()` 中将 setTimeout 存入 `timerId`，在 `Promise.race().finally()` 中 `clearTimeout(timerId)`，确保 fetch 完成后立即清除超时定时器。

2. **`src/pages/Companion/index.ux`**:
   - 新增 `MAX_HISTORY = 100`，`_trimHistory()` 自动裁剪超出上限的历史
   - `saveHistory()` 增加防抖（3s）+ 内容变化检测（`_lastSavedLength`）
   - `onHide()` 立即执行一次持久化（跳过防抖）避免数据丢失

3. **`src/helper/navigate.js`**: 
   - 用 `acquireLock()` 统一管理锁，每次调用清除上一次的释放定时器
   - 新增 `LOCK_MAX_DURATION = 2s` 安全兜底，即使异常也不会永久锁死

4. **`src/pages/Memory/index.ux`**: `loadFromLocal()` 增加 `_loadingLocal` 防抖标志，防止并发加载。

5. **`src/pages/ProfileDetail/index.ux`**: `loadProfiles()` 增加 `_loadingProfiles` 防抖标志，防止并发请求。

### 补充修复（传承页面跳转卡死）

用户反馈：传承(Memory)页面与任意其他页面来回跳转 ~10 次即卡死。

**根因**: `router.replace()` 每次切回 Memory 都创建全新实例，`onInit` → `loadFromLocal(callback)` → `syncWithBackend()` → POST /cards/sync。跳转 10 次 = 10 个 HTTP sync 请求堆积，快应用 fetch 连接池耗尽，框架卡死。

**修复** (`src/pages/Memory/index.ux`):
- 移除 `onInit` 中的 `syncWithBackend()` 调用，仅做本地加载
- 新增 `_trySync()` 方法，使用全局时间戳 `hook2global.__kv_mem_sync_ts` 做跨实例保护
- 间距 ≥ 30 秒才触发后端同步，30 秒内任意多次切页只发 1 次请求
- `onDestroy()` 增加 `_timers` 清理，防止定时器泄漏
