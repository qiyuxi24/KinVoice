## 关键发现
1. main.py 只注册了 convert_router，chat 和 cards 路由未注册 → POST /chat 和 CRUD /cards 不可用
2. Card ORM 字段与 Pydantic Schema 字段完全不同 → cards CRUD 会失败
3. Memory 页采用在线+本地双写策略，离线兜底
4. BreakIce 页的 POST /convert 是唯一已打通的前后端链路

## 卡片 CRUD 修复 + 数据库初始化 (2025-06-20 上午)
- **ORM 模型重写**：`card.py` 字段改为 `id/category/emotion/observation/feeling/need/request/created_at/updated_at`，与 Schema 对齐
- **路由注册**：`main.py` 新增 `chat_router` + `memory_router` 注册
- **新增 PUT /cards/{id} 更新接口**：支持部分字段更新，过滤非 ORM 字段
- **session 依赖注入**：`db/session.py` 新增 `get_session()` 生成器（commit/rollback 自动管理）
- **前端适配**：

- **config.py**：`DEBUG` 改为 `str` 类型避免与系统环境变量 `DEBUG=release` 冲突
