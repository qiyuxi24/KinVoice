# 2026-07-04

## 前端报错码显示机制

实现了全局报错码显示系统，当前端逻辑出错时在页面顶部显示报错码浮层。

### 新增文件
- `src/helper/errorBus.js` — 全局错误事件总线（pub/sub），挂在 `global.$errorBus`
- `src/components/ErrorToast/index.ux` — 页面顶部浮动报错码组件，自动监听总线，队列显示错误

### 修改文件
- `src/app.ux` — 导入 ErrorToast 组件 + 注入 `$errorBus` 到 global
- `src/helper/utils.js` — 新增 `showErrorCode(err, context)` 方法（推送到浮层 + 系统 toast）
- `src/helper/ajax.js` — 所有网络错误自动 `emitError()` 到总线（超时/HTTP错误/网络层错误）
- `src/pages/Companion/index.ux` — 3 个 catch 处加入 showErrorCode
- `src/pages/BreakIce/index.ux` — 4 个 catch 处加入 showErrorCode
- `src/pages/Memory/index.ux` — 8 个 catch 处加入 showErrorCode
- `src/pages/ProfileDetail/index.ux` — 6 个 catch 处加入 showErrorCode

### 工作机制
1. **网络层**（ajax.js）：自动推送 → 无需业务代码感知
2. **业务层**（页面代码）：`$utils.showErrorCode(err, '上下文')` 手动调用
3. **存储层**：`$utils.showErrorCode({ code: 400x, message: '...', level: 'warn' })` 手动调用
4. ErrorToast 组件显示：`[1001] 网络请求超时` 格式，按 level 着色（红/橙/灰），自动 2-4 秒消失，支持队列
