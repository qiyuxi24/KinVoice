- 解耦设计：models/schemas/api 三层各自独立修改，无交叉依赖


## P0 #2: 统一 user_id 传递方式 (Header Depends)

### 核心原则
- 后端全部通过 `X-User-Id` Header + `Depends(get_user_id)` 获取 user_id
- 前端 `ajax.js` 自动注入 `X-User-Id` Header（从 `userIdentity.getUserId()`），各 API 模块无需手动传
- 废弃 body/query 参数中手动传 `user_id` 的方式

### 后端改动
| 文件 | 改动 |
|------|------|
| `schemas/chatroom.py` | SendMessageRequest 移除 `user_id` 字段 |
| `schemas/profile_ai.py` | ProfileUpdateRequest 移除 `user_id` 字段（改为空模型） |
| `api/chatroom.py` | send_message/get_messages/list_conversations: 全部改用 `Depends(get_user_id)` |
| `api/family.py` | 移除 4 个内联的含 user_id 请求模型，改用 schemas/family.py 的纯业务模型 + `Depends(get_user_id)` |
| `api/profile_ai.py` | update_dynamic/update_stable/read_profile: 全部改用 `Depends(get_user_id)` |

### 前端改动
| 文件 | 改动 |
|------|------|
| `ajax.js` | 新增 import userIdentity，fetchPromise 中自动注入 X-User-Id Header |
| `chatroom.js` | 移除 uid() 辅助函数 + 3 处手动 user_id 传参 |
| `family.js` | 移除 uid() + 5 处手动 user_id 传参 |
| `profile_ai.js` | 移除 3 处手动 user_id 传参，3 个方法全部改为无参 |
| `Companion/index.ux` | updateDynamic('default') → updateDynamic() |
| `Profile/index.ux` | updateStable('default') → updateStable() |

### 验证
- 所有后端 API 零 lint 错误
- 重建数据库成功
- get_user_id 中间件兼容模式保留（无 Header 时默认 "1"）


## 新增：用户登录系统（账号密码）

### 设计
- **账号体系**：用户名 + 密码（替代设备 UUID），密码用 PBKDF2-SHA256 加盐哈希
- **注册/登录 API**：`POST /auth/register`（username + password + nickname）→ 返回 user_id；`POST /auth/login`（username + password）→ 返回 user_id + nickname
- **Profile 页面**：未登录时显示"点击登录"，点击头像展开登录/注册面板；已登录时显示"你好，{昵称}" + 家庭组信息 + 退出按钮
- **后端 user_id**：服务端生成 UUID（`uuid.uuid4()`），不再依赖前端 device UUID

### 新增/修改文件
| 文件 | 改动 |
|------|------|
| `backend/app/models/family.py` | User 新增 `username`(unique)、`password_hash` 字段 |
| `backend/app/utils/password.py` | 新建：PBKDF2-SHA256 密码哈希/验证工具 |
| `backend/app/schemas/auth.py` | 新建：RegisterRequest、LoginRequest、AuthResponse |
| `backend/app/api/auth.py` | 新建：POST /auth/register、POST /auth/login |
| `backend/app/main.py` | 注册 auth_router |
| `src/helper/apis/auth.js` | 新建：login()、register() |
| `src/helper/userIdentity.js` | 重写：登录态管理（init/login/register/logout/isLoggedIn），本地存储 user_id + nickname |
| `src/pages/Profile/index.ux` | 重写：登录态检测、登录/注册面板 UI、退出登录 |

### 用法
- cd backend && del data\kinvoice.db && python init_db.py（重建库）
- Profile 页面 → 点击头像 → 输入用户名密码登录
- 登录后 user_id 存入 localStorage，后续所有 API 请求自动携带
