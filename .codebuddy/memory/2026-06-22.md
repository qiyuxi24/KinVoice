### 白屏问题修复（2026-06-22 15:01）

**根本原因：** `src/helper/apis/index.js` 使用了 `require.context()`，这是 Webpack 专属 API，快应用 V8 引擎不支持，导致 `app.ux` 初始化时直接抛出 `TypeError: require.context is not a function` → 应用崩溃白屏。

**次要原因：** `src/app.ux` 缺少 `<template>` 根节点（快应用 .ux 文件必须有 template + script + style 三部分）。

**修复：**
- `apis/index.js`：改为手动 `import` 所有模块（cards/chat/config/convert/profiles），再 `export default`
- `app.ux`：添加 `<template><div></div></template>`，同时把 `require().default` 改为 ESM `import`
